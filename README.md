we build a simple Secret Door Alarm using Arduino, a Reed Sensor, Magnet and Buzzer! 🚪🔔

When the door is closed, the magnet stays near the reed sensor. When someone opens the door, the magnet moves away and the buzzer turns ON, creating an instant alarm.
